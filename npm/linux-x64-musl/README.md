# supersynth-linux-x64-musl

The native engine of [supersynth](https://www.npmjs.com/package/supersynth) for Linux x64 (musl, Alpine)
(`supersynth.linux-x64-musl.node`, built by CI from `native/`). Install `supersynth`, not this package: npm
picks the right engine for the platform as one of its optional dependencies.
