# @supersynth/linux-arm64-gnu

The native engine of [supersynth](https://www.npmjs.com/package/supersynth) for Linux arm64 (glibc 2.35+; e.g. a Raspberry Pi 4/5 on 64-bit Raspberry Pi OS Bookworm)
(`supersynth.linux-arm64-gnu.node`, built by CI from `native/`). Install `supersynth` rather than this package; npm
picks the right engine for your platform from its optional dependencies.
