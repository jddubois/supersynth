# supersynth-linux-arm64-gnu

The native engine of [supersynth](https://www.npmjs.com/package/supersynth) for Linux arm64 (glibc; Raspberry Pi 4/5 with a 64-bit OS)
(`supersynth.linux-arm64-gnu.node`, built by CI from `native/`). Install `supersynth`, not this package: npm
picks the right engine for the platform as one of its optional dependencies.
